# Junk Magnet

Top-down survivors-like for CrazyGames. Design and build plan: [SPEC.md](SPEC.md).

```bash
npm install
npm run dev      # play locally
npm run build    # type-check + static build in dist/
```

Status: milestone 1 (grey-box prototype) — move, bump Tin Bots, collect and orbit junk, junk damages bots.
Balance numbers live in `src/data/*.json`.
