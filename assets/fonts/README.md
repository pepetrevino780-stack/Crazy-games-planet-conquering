# Fonts

- **Pixelify Sans** (variable weight, `PixelifySans.woff2`): body text, numbers and map labels.
- **Silkscreen** (`Silkscreen-400.woff2`, `Silkscreen-700.woff2`): headings and button labels.

Both fonts come from Google Fonts and are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). They are bundled here so the game makes no external requests.
